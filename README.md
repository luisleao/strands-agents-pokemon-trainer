# Crie seu Assistente Pokémon

Este workshop foi construído para exemplificar o uso de [Strands Agents](https://strandsagents.com/?trk=6ac81577-2c30-4287-a906-3e10c4cf7625&sc_channel=el).


> Caso você esteja no HackTown 2026 e tenha concluído este workshop, compareça na AWS Developers House a mostre o que construiu para nosso time



## Requisitos

- Python 3.10+
- UV
- [Ollama](https://ollama.ai/)


## Como executar este workshop?

* Utilize a pasta `steps` para executar o passo-a-passo do nosso workshop.
* Você deve executar as etapas em todos os passos de forma sequencial.
* Você deve alterar unicamente o arquivo `app.py`
* Os passos obrigatórios são do 1 ao 5 na pasta [steps](steps/). 
* Deixamos algumas ideias sobre o que fazer além do workshop no passo 6.
